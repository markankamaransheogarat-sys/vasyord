# Пресс-релиз: Vasyord (Васёрд) v1.0.0

**Дата:** 20 ноября 2026  
**Репозиторий:** https://github.com/markankamaransheogarat-sys/vasyord  
**Лицензия:** MIT  

## Заголовок
**Vasyord v1.0.0 — лёгкая self-hosted альтернатива Discord с WebRTC-голосом, мобильным интерфейсом и Docker-деплоем**

## Ключевые возможности релиза v1.0.0
- **P2P WebRTC Voice (Opus 48kHz)** с шумоподавлением, эхоподавлением и VAD-индикацией.
- **Сигнальный сервер на Express + Socket.io** с персистентной историей сообщений комнат.
- **Мобильный и десктопный интерфейс** на React + TypeScript + Vite.
- **Готовый `docker-compose.yml`**, healthcheck-эндпоинт `/health`, автотесты (`node:test`) и GitHub Actions CI.
